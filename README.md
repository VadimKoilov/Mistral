# Mistral — управление вентиляторами для MacBook Pro (Apple Silicon)

Меню-бар приложение для macOS: показывает температуру CPU/GPU и обороты вентиляторов,
умеет крутить их вручную и **автоматически разгоняет охлаждение при нагрузке** —
чтобы мак не троттлил во время сборки проекта, генерации файлов и запуска тяжёлых
приложений (DeviceHub и т.п.).

> 🛠 Для доработок и понимания внутреннего устройства см. [DEVELOPMENT.md](DEVELOPMENT.md) —
> архитектура, SMC-слой, протокол хелпера, регулятор, грабли и roadmap.

Протестировано на **MacBook Pro 14" (M1 Pro, macOS 27)**. Подойдёт и для других
Mac на M1/M2/M3 с вентиляторами (ключи датчиков M1-семейства уже вшиты; для
вентиляторов используется универсальный интерфейс SMC).

## Установка

1. Скопируйте `dist/Mistral.app` в **Программы** (/Applications):
   ```bash
   cp -R Mistral/dist/Mistral.app /Applications/
   ```
2. Запустите Mistral — в строке меню появится значок 🌀 с текущей температурой.
3. Клик по значку → панель. Для управления вентиляторами один раз нажмите
   **«Установить…»** и введите пароль администратора — будет установлен
   привилегированный помощник `mistrald` (то же самое делают Macs Fan Control и Stats:
   macOS разрешает запись оборотов только root).
4. Выберите режим **«Авто»**. Готово.
5. Включите **«Запускать при входе в систему»**, чтобы автоохлаждение работало всегда.

### Установка помощника вручную (альтернатива кнопке)

```bash
sudo cp '/Applications/Mistral.app/Contents/MacOS/mistrald' /usr/local/mistral/mistrald 2>/dev/null || {
  sudo mkdir -p /usr/local/mistral
  sudo cp '/Applications/Mistral.app/Contents/MacOS/mistrald' /usr/local/mistral/mistrald
}
sudo chmod 755 /usr/local/mistral/mistrald
sudo chown root:wheel /usr/local/mistral/mistrald
sudo sh -c 'printf '$(id -u)' > /usr/local/mistral/owner.uid'
# plist лежит в бандле: скопируйте из /tmp после первого запуска Mistral, либо создайте сами:
sudo launchctl bootstrap system /Library/LaunchDaemons/app.mistral.helper.plist
```

## Как пользоваться

Клик по значку 🌀 **температура** в строке меню открывает компактное меню:

- **Показать Mistral** — полное окно панели (график, слайдеры, статус помощника)
- **Доступные вентиляторы** — для каждого вентилятора подменю: «Системное авто»,
  «Максимальные обороты» и список фиксированных оборотов (галочка — текущий режим)
- **Профили** — Системное управление / Тихо / Стандарт / Производительность / Турбо /
  Максимальные обороты (галочка — активный профиль)
- **Настройки…** — то же окно панели
- **Ещё** — автозапуск при входе, буст по нагрузке CPU, удаление помощника
- **Завершить Mistral** — выход (вентиляторы возвращаются системе)

## Как работает авто-режим

Опрос каждые 2 секунды: берётся максимум температуры P/E ядер CPU (ключи SMC
`Tp01`, `Tp05`, `Tp0D`, `Tp0H`, `Tp0L`, `Tp0P`, `Tp0X`, `Tp0b`, `Tp09`, `Tp0T`).

Целевые обороты = доля от диапазона [1200 … max] вентилятора по кусочно-линейной кривой:

| Профиль | Базовые обороты | Начало разгона | ~90% к | 100% при |
|---|---|---|---|---|
| Тихо | ~20% | 50°C | 78°C | 88°C |
| Стандарт | ~25% | 48°C | 75°C | 85°C |
| **Производительность** (по умолчанию) | ~32% | 45°C | 70°C | 80°C |
| Турбо | ~45% | 40°C | — | 60°C |

Плюс два предиктивных буста (можно отключить галку «Буст при высокой нагрузке CPU»):
- **резкий рост температуры** (>0.25°C/с) → +12% оборотов заранее, пока мак ещё не прогрелся;
- **высокая нагрузка CPU** (>60% в течение нескольких тиков — как раз сборка/генерация файлов) → +10%.

Скорость подъёма мгновенная, спуск плавный (не быстрее 6%/тик) — без «пилы».
При ≥92°C вентиляторы принудительно на максимум.

## Безопасность

- При **выходе из приложения**, **переходе в режим «Система»** и **уходе в сон**
  вентиляторы возвращаются под штатное управление macOS (сброс `Ftst`, `F0Md=0`).
- Обороты всегда ограничены диапазоном [min…max] конкретного вентилятора.
- Если хелпер перестаёт отвечать, приложение само возвращает системное управление.
- После перезагрузки мака всё также возвращается к штатному поведению.

## Сборка из исходников

```bash
cd Mistral
./scripts/build-app.sh     # → dist/Mistral.app
```

Режимы отладки:
- `Mistral.app --debugwindow` — панель отдельным окном;
- `Mistral.app --snapshot /tmp/panel.png` — PNG-снимок панели.

Диагностика SMC (сборка отдельно):
```bash
swift build --target Probe
.build/debug/Probe            # вентиляторы + температуры
.build/debug/Probe --all      # дамп всех ключей T*
.build/debug/Probe --watch 30 # мониторинг 30 сек
```

## Удаление

- В панели: «Удалить помощника» (спросит пароль) → затем удалите приложение.
- Или вручную:
  ```bash
  sudo launchctl bootout system/app.mistral.helper
  sudo rm -rf /usr/local/mistral /Library/LaunchDaemons/app.mistral.helper.plist /var/run/mistralctl.sock
  ```

## Структура проекта

```
Sources/SMCCore/    — доступ к AppleSMC (user client, 80-байтная структура),
                      декодирование/кодирование значений (flt/fpe2/sp78/uiN…)
Sources/Mistrald/   — root-хелпер: UNIX-сокет /var/run/mistralctl.sock,
                      команды PING/SETT/MODE/RESET, проверка uid клиента
Sources/Mistral/    — приложение меню-бара: NSStatusItem + NSMenu (как у Macs
                      Fan Control), окно панели на SwiftUI, авто-регулятор,
                      установка хелпера через нативный диалог пароля
Sources/Probe/      — CLI-диагностика SMC
scripts/            — сборка бандла, иконка, Info.plist
```
